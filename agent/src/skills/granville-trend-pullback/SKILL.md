# Granville Trend Pullback

评估葛兰碧多头法则 2 与法则 3。两者都要求已有上升趋势，区别在于价格是否曾以**完整交易日收盘**跌破所选均线：

- **法则 2：假跌破后收复**——价格原本位于上升均线上方，短暂收盘跌破，随后完整交易日收盘重新站回均线上方并出现转强证据。
- **法则 3：回调获支撑**——价格从均线上方回调，完整交易日收盘始终守在上升均线上方，随后止跌转强。

均线是趋势状态和风险位置参考，不是触及即买的机械信号。本技能只做形态识别、证据分级和失效条件说明；除非用户另行要求，不生成仓位或订单，也不调用交易、账户写入或下单工具。

## 默认口径

- 用户指定均线、周期、市场或截止日时遵从用户设置。
- 用户只说“法则 2/3”或“200MA 回调”时，默认使用日线 `SMA200`，评估最近一个完整交易日；不得把盘中未完成 K 线当作确认。
- 美股代码使用 `<TICKER>.US`。调用 `get_market_data` 时使用 `interval="1d"`、`lookback=250`、`max_rows=0`，取得连续、未抽样的完整 OHLCV。
- 均线计算使用与价格相同的复权口径。不得混用复权均线、未复权价格或不同来源的最新价。
- 至少需要 `均线周期 + 20` 个有效交易日，用于计算均线并观察方向；默认 `SMA200` 因此至少需要 220 日，优先取得 250 日。
- 报告行情数据源、复权口径、最后完整交易日和精确 `as_of`。实时价只能作为补充，不改变完整日线形态结论。

若用户指定 EMA、周线或其他均线，沿用以下流程，但必须明确参数已经改变；不得把结果继续称为默认 `SMA200` 结论。

## 工作流

### 1. 验证数据与趋势前提

1. 检查日期严格递增、无重复，所需 OHLCV 和均线输入非空，价格为正，窗口覆盖充足。
2. 计算用户指定均线；默认：

```text
MA[t]       = mean(Close[t-199:t])
ma_slope_20 = MA[t] / MA[t-20] - 1
distance[t] = Close[t] / MA[t] - 1
```

3. 只有 `MA[t] > MA[t-20]` 时，默认把均线方向记为上升。必须同时报告 `MA[t]`、`MA[t-20]` 和 `ma_slope_20`，不得只写“均线向上”。用户指定其他斜率窗口时使用用户值并披露。
4. 检查回调前价格是否主要运行在均线上方，以及高低点结构是否仍支持上升趋势。一次向上穿越不等于已有上升趋势。
5. 均线走平或下降时，法则 2/3 的必要前提不成立；即使价格反弹，也不得评为符合。

### 2. 区分法则 2 与法则 3

以完整交易日收盘相对当日均线的位置作为主分类依据，同时报告盘中 `Low` 是否穿越均线。

#### 法则 2：假跌破后收复

必须同时验证：

1. 回调前价格位于上升均线上方；
2. 回调中至少一个完整交易日 `Close < MA`，并记录首次跌破日、最低收盘及最大负乖离；
3. 随后一个完整交易日 `Close > MA`，并记录首次收复日、收复收盘及相对均线距离；
4. 跌破是有限回调，尚未形成持续位于均线下方、均线转弱或下降高点/下降低点主导的新趋势；
5. 已出现可核查的重新转强证据，例如收复日后突破收复日高点，或低周期形成更高低点。只有收复、尚无转强确认时标为“部分符合/等待确认”。

不得把盘中一度跌破但收盘始终在均线上方归为法则 2；这类情况进入法则 3 检查，并单列盘中刺穿。

#### 法则 3：回调获支撑

必须同时验证：

1. 回调前价格位于上升均线上方；
2. 回调期间完整交易日 `Close >= MA`，没有发生法则 2 所要求的收盘跌破；
3. 价格确实接近均线，必须报告最小 `distance`、对应日期和盘中最低价相对均线的位置，不得用“靠近”代替数值；
4. 回调没有演变为放量破位、持续波动扩张或下降高低点结构；
5. 已出现止跌转强证据，例如反转日后突破其高点、形成更高低点，或重新收复回调中的短期结构位。只有触及/接近均线、尚未转强时标为“部分符合/等待确认”。

若盘中 `Low < MA` 但完整收盘仍在均线上方，报告刺穿幅度和收盘恢复情况。轻微刺穿不自动改成法则 2，也不自动证明法则 3；结合波动、成交量和后续确认分级。

### 3. 检查反证与失效条件

以下情况优先视为反证，不能被一次反弹掩盖：

- 均线走平或下降；
- 价格已连续多个完整交易日位于均线下方，且没有及时收复；
- 收复后再次收盘跌破，并跌破本轮回调低点；
- 回调中出现持续放量下跌、波动扩张或明确的下降高点/下降低点；
- 大盘或行业同步转弱，个股相对强弱明显恶化；
- 公司事件导致价格跳空穿越均线，使普通趋势回调假设失去解释力。

给出两个不同概念，不得混为一谈：

- **形态失效**：哪一个完整收盘、回调低点或趋势结构变化会让法则 2/3 的判断不再成立。
- **交易止损**：只有用户明确要求制定交易计划时才讨论；不得把均线本身自动当作止损价。

## 结论分级

每个标的必须先给出以下四类之一，再解释证据：

- **符合**：上升趋势前提成立，法则 2 或 3 的路径完整，且已有重新转强确认。
- **部分符合**：趋势与回调位置成立，但尚未收复、尚未转强，或存在需要核验的盘中刺穿/反证。
- **不符合**：均线方向、价格路径或趋势结构明确不满足，或反证已经推翻形态。
- **无法判断**：数据窗口、完整交易日、复权口径或关键 OHLCV 不足。未知不得当作部分符合。

法则 2 与法则 3 不得同时判为“符合”。若路径跨越两类，按完整收盘是否跌破均线归类，并说明另一类为何排除。

## 输出格式

先给结论，再给数据与推导：

```markdown
## 结论（as of YYYY-MM-DD）

| 代码 | 结论 | 归类 | 触发状态 | 最新收盘/均线 | MA 20日斜率 | 回调关键日 | 转强证据 | 主要反证 | 形态失效 |
|---|---|---|---|---:|---:|---|---|---|---|

### 证据
- 数据源、复权口径、完整交易日与参数：
- 回调前趋势：
- 法则 2 跌破/收复路径，或法则 3 守线/反弹路径：
- 成交量、波动、市场/行业与相对强弱：
- 尚缺证据：
```

必须引用具体日期、收盘、均线值、乖离和斜率。若评估多个标的，统一数据截止日和参数后再比较；无法对齐时明确分组，不得用不同截止日结果直接排序。
